# Tools

Ad-hoc debug and inspection scripts. **Not** part of the production audit pipeline.

| Script | Purpose |
|--------|---------|
| `inspect_gap.py` | Inspect gap report JSON |
| `inspect_evidence.py` | Inspect scrubbed evidence |
| `check_batch.py` | Batch state checks |
| `check_all_formats.py` | Document format coverage |
| `_check_place.py` | Placement debugging |
| `snapshot_findings.py` | Snapshot Layer 1 findings for comparison |
| `generate-flow-svgs.py` | Regenerate `docs/images/*.svg` flow canvases |

Use during development only.
