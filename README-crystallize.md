# Crystallize (historical)

Crystallize was the read-only curriculum auditor that Loom grew out of. It
classified documents but then ran the same generic analysis on everything.

**Loom supersedes and replaces Crystallize.** Loom keeps the same decomposition
and classification engine and adds a router so each document type flows through
the right workflow (Path A–H).

- [README.md](README.md) — Loom overview
