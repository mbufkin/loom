# Path A pass set for world-class review

## Question

For world-class Path A, which **passes** do we keep, drop, merge, or add relative to today’s A1–A8 — given the rule “isolate what we’re looking for → is it there? → short quality call on what’s there” — and what is explicitly *not* a pass?

## Answer

**Keep A1–A8 as the Path A pass set** — prior Path A is the baseline; do not reshape into a new pass taxonomy.

**Add** a thin **why + improve** layer on every **rating** pass:

| Pass | Role | Why + improve? |
|------|------|----------------|
| **A1** | Inventory (structural) | No — lists evidence, doesn’t rate |
| **A2–A7** | Rating passes | **Yes** — short why for the status/quality call + auditor cue for what to add/clarify |
| **A8** | Emit (structural) | No — packaging only |

**Improve language (locked here):** auditor cues only — what’s missing/weak in the **written evidence** and what to add/clarify. **Never** draft lesson text, TEKS wording, or activities.

**Explicitly not a pass:** classroom observation scores; inventing content; essay-length commentary; new top-level path letters; replacing A1–A8 with a different pass set.

**Deferred to** [Quality-call rubric on PRESENT elements](./03-quality-call-rubric.md): exact quality labels and why/improve phrase shape/length.
