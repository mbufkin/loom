# One-page Path A shared artifact

## Question

What does the **one shared short Path A artifact** look like (sections, density, cite style) such that a teacher, coach, and auditor can each act from the same page in under two minutes — and what must never appear on it (essays, invented content, observation scores)?

## Answer

**Locked section order** (prototype ratified): [04-one-page-path-a-prototype](../assets/04-one-page-path-a-prototype.md)

1. Header (unit/doc · shared readers · auditor-only rule)
2. **Top gaps** (act first) — each with status/quality, *Why*, *Improve*
3. **What’s working (PRESENT)** — short table: pass · item · Strong/Adequate/Weak · short why
4. **Hunter at a glance (A5)** — present count + focus-improve line
5. **Evidence pointers** — short pointers only (not the grade; no table dumps)
6. **Never on this page** — essays, drafted rewrites, observation/T-TESS teaching scores, new path letters

**Density:** this shape is the one shared page for teacher + coach + auditor. Production cites stay short.

**Improve language:** auditor cues only (per [Path A pass set](./02-path-a-pass-set.md) + [Quality-call rubric](./03-quality-call-rubric.md)).
