# Quality-call rubric on PRESENT elements

## Question

When an element is PRESENT, what **short quality labels** (and evidence rules) may Path A attach — so we get “is it of quality?” without sliding into teacher evaluation or inventing content? Charting already locked the layering (presence first, then quality with evidence); this ticket locks the vocabulary and stop-lines.

## Answer

**Layering (unchanged):** presence/alignment status first → then quality (when allowed) → then why + improve (A2–A7).

**Quality labels (three-way), only if status is PRESENT:**

| Label | Meaning (practitioner lens) |
|-------|-----------------------------|
| **Strong** | Clear plan + usable steps/path for teaching |
| **Adequate** | Element present, but path is vague/incomplete |
| **Weak** | Labeled present, but does **not** give a teacher a usable move |

**When quality labels are forbidden:** `MISSING` and `MISALIGNED` — those get **why + improve only** (no Strong/Adequate/Weak).

**Evidence rule:** Loom may still **point at** whatever written evidence it found (excerpts/ids) as support for the call. Quality is **not** citation density or academic “cited work” — real lesson plans rarely look like that. Judge the **usable teaching path**.

**Why + improve:**
- Preferred brief; **up to a short paragraph each** if needed (not hard-capped).
- Why = why this status/label.
- Improve = auditor cues only (what’s missing/weak in the written materials; what to add/clarify).
- **Stop-lines:** no drafting lesson text; no classroom-observation scores; no teacher evaluation language.

**Ties to** [Path A pass set for world-class review](./02-path-a-pass-set.md): why+improve on A2–A7; A1/A8 structural.
