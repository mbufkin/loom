# Syllabus quality research (Path G)

**Ticket:** [10-syllabus-quality-research](../tickets/10-syllabus-quality-research.md)  
**Question:** What makes a good **course syllabus** as a review target (not a lesson plan), especially for **DISD / Texas CTE high school**, and how should Loom Path G differ from Path A?  
**Date:** 2026-08-04  
**Scope:** Written course syllabus / course expectations document. Not classroom observation. Not inventing syllabus text.

---

## 1. Verdict (short)

A strong syllabus is a **course-level student-facing contract and learning map**: who/what/when, why the course matters, measurable outcomes, transparent grading, a TEKS-covering timeline, workable policies, and CTE extras (safety, WBL, signatures). Path G must review that **course grain** — not Hunter daily structure (Path A) and not YAG/pacing alone (Path F). Loom should copy learner-centered **presence + alignment** habits, adapt them to Texas CTE expectations, and keep auditor-only output (PRESENT/MISSING/MISALIGNED + short why/improve).

---

## 2. What a syllabus is (vs Path A / Path F)

| Artifact | Grain | Student job | Loom lens |
|----------|-------|-------------|-----------|
| **Lesson plan** | One instructional episode | Learn today’s objective | **Path A** |
| **YAG / pacing / S&S** | Year/unit spine for teachers & champions | (mostly staff) | **Path F** |
| **Syllabus** | Whole course, student + family facing | Know how to succeed and what counts | **Path G** |

Path G is **not** “Path A with different filenames.” Hunter plates, CFU, and daily gradual release are the wrong inventory. Syllabus review asks: *Can a student (and family) see the course bargain, the success path, and the TEKS/timeline claim?*

Champion map historically listed course syllabus as **out of scope** (presence only). Path G closes that gap as a first-class lens.

## 3. Research / practice bases

### A. Learner-centered syllabus (higher-ed research → reusable criteria)

Sources: Duke LILE learner-centered syllabus toolkit; Notre Dame syllabus review checklist; CMU / WashU syllabus templates; O’Brien, Millis & Cohen (*The Course Syllabus: A Learning-Centered Approach*); Palmer et al. on syllabus as invitation.

Recurring elements Loom can audit as **presence** (not tone-police essays):

1. Course identity + logistics (description, prereqs, contact, meeting pattern)
2. Student-centered learning objectives (action verbs; what students will *do*)
3. Activities / assignments overview aligned to those objectives
4. Assessment + grading plan (weights, scale, feedback expectations)
5. Course topics / schedule / due dates
6. Communication expectations
7. Policies (integrity, attendance, late work, AI when stated)
8. Support resources / how to succeed / accommodations pointers

**Tone / belonging** (inclusive language, “you will”) matters in research but is **soft** for an auditor: flag only when the document is pure punitive contract with no success cues — never rewrite the syllabus voice.

### B. Texas CTE / TEA class-expectations practice (primary for DISD)

Sources: Texas CTE Resource Center / TEKS Guide *Establishing Class Expectations* (syllabus + timeline so TEKS are covered); TEA-oriented WBL guidance (grading, attendance, parent/guardian acknowledgment); sample DISD-style CTE syllabi (course contents tied to YAG units, weighted categories, safety, internship hours).

CTE-first checklist additions:

| Element | Why it matters |
|---------|----------------|
| **TEKS / course goals + timeline** | Syllabus + timeline structure learning so course TEKS are covered and deadlines are visible |
| **Grading policies** | Students know how the grade is earned (including WBL/internship weight when applicable) |
| **Attendance expectations** | Especially when work component affects grade |
| **Safety rules** | Shop/lab/clinical CTE environments |
| **Program / course rules** | Discipline and professional work ethic |
| **Parent/guardian + student acknowledgment** | TEA-recommended for WBL / high-stakes course responsibilities |
| **Employability / professional standards** | Chapter 127 career-development / CTE expectations increasingly explicit |
| **Link to YAG / units** | Student-facing map should not contradict champion YAG |

### C. Alignment (UbD + curriculum audit)

- **UbD** at *course* grain: outcomes → evidence (graded categories) → learning sequence (calendar/units).
- **Fenwick English** triangulation: written syllabus vs assessed plan vs (later) taught — Loom stays on written match/mismatch.
- **T-TESS 1.1** language for measurable outcomes aligned to TEKS — document checklist, not teacher eval.
- **EdReports / gateway thinking:** missing core gates (identity, outcomes, grading, timeline) fail before soft quality polish.

## 4. Proposed Path G pass set (own thing)

| Step | Name | Anchor | Loom check |
|------|------|--------|------------|
| **G1** | Inventory cited chunks | Curriculum audit | Layer 0 excerpts for this syllabus doc |
| **G2** | Course identity & logistics | TEA expectations; district norms | Course name/PEIMS or local #, credit/grade band, teacher contact, meeting pattern, prereqs |
| **G3** | Purpose & learning outcomes | Learner-centered objectives; UbD Stage 1; T-TESS 1.1 | Why-course / description + measurable course outcomes or TEKS-facing goals |
| **G4** | Assessment & grading transparency | TEA grading procedures; Duke assessment plan | Categories + weights, scale, late/makeup, how feedback works |
| **G5** | Course map / TEKS timeline | TEA syllabus+timeline; UbD Stage 3 course map | Units/topics, major dates, claim that TEKS/course content is sequenced |
| **G6** | Policies & communication | Learner-centered policies; TEA attendance/rules | Attendance, integrity, communication channels/response norms |
| **G7** | Access, safety, CTE/WBL | ELPS/UDL light; TEA safety + WBL signatures | Accommodations/supports, safety, WBL/internship, parent/student acknowledgment when CTE signals present |
| **G8** | Cross-artifact alignment | English triangulation; Path F handoff | Syllabus ↔ YAG/pacing/S&S; outcomes ↔ grade categories (MISALIGNED when contradict) |
| **G9** | Emit Path G artifacts | Shared short artifact habit | `path_g/findings.json` + short syllabus one-pager (gaps → working → evidence) |

### Quality calls (later, after presence works)

Reuse Path A’s **PRESENT-only** Strong / Adequate / Weak with why+improve (auditor cues, never draft syllabus text). Soft tone/belonging stays out of hard gates.

### Guardrails

- Blank / MISSING = not found  
- No authored policies, TEKS lists, or calendars  
- No Hunter plate  
- Do not treat Path F docs as syllabi; do not treat syllabi as lesson plans

## 5. Copy / adapt / avoid

| Move | Detail |
|------|--------|
| **Copy** | Presence→quality layering; claim→why→improve; ≤3 top gaps on one-pager; UbD alignment; TEKS timeline expectation from TEA CTE practice |
| **Adapt** | Learner-centered college checklists → CTE HS student/family document; WBL/safety/signatures as G7 when signals present; Path F cross-check as G8 |
| **Avoid** | Hunter A5/A6 reuse; observation Domains 2–3; inventing syllabus language; grading “teacher niceness”; collapsing syllabus into YAG (F) or lesson (A) |
