# Trust scorecard — worked example on the Path A one-pager prototype

**Sample under test:** [04-one-page-path-a-prototype.md](./04-one-page-path-a-prototype.md)  
**How to use:** For each gate, mark YES or NO. **Any NO = sample fails.**  
This is not grading the teacher — it’s grading whether *our review page* is trustworthy.

---

## Core 4 (smallest checklist)

| Gate | Meaning in plain English | Prototype? | Notes |
|------|--------------------------|------------|-------|
| **C1** | Top gaps come first, and each gap has a **Why** and an **Improve** | YES | ELPS, accommodations, objective clarity all have both |
| **C2** | Fits **one page** / about **2 minutes** to read | YES | Short sections; no essay |
| **C3** | Improve only says what to **add/clarify** in the materials — does **not** write the lesson | YES | “Add a short language objective…” — cue, not a drafted lesson |
| **C4** | No essays, no classroom observation / teaching scores, no invented content | YES | Explicit “Never on this page” |

**Core-4 result on prototype: PASS**

---

## Locked extras (+ G8)

| Gate | Meaning | Prototype? | Notes |
|------|---------|------------|-------|
| **X5** | Section order matches the locked shape (gaps → working → Hunter → evidence) | YES | Matches locked order |
| **X6** | Strong / Adequate / Weak only appear on **PRESENT** items (not on MISSING) | YES | MISSING gaps have no quality label; table uses labels on PRESENT |
| **X7** | Evidence pointers stay **short** (no table dumps / bleed across units) | YES | Three short bullets; prototype calls out “not table dumps” |
| **G8** | At most **3** Top gaps | YES | Prototype has exactly 3 |

**Locked set (C1–C4 + X5–X7 + G8) on prototype: PASS**

---

## What a FAIL would look like (contrast)

| Gate | Fail example |
|------|----------------|
| C1 | “ELPS missing” with no Why/Improve |
| C2 | 6-page findings dump |
| C3 | Improve pastes a full rewritten objective + activities |
| C4 | “T-TESS 2.1 was weak in delivery” (observation) |
| X6 | “MISSING · Weak” on ELPS |
| X7 | Pasting a whole `--- TABLE ---` TEKS block as the cite |
| G8 | Five “top” gaps fighting for attention |

## Locked choice

**Core 4 + X5–X7 + G8** — hard gates; any NO fails the sample.
