Graph sort: one authority, two careful model steps

After ingest + Layer 0 decompose, the graph is the only place that decides what a document is and how it hangs on the course. Paths A–H are a thin lookup from that decision — not a second sort.

One pass or two? Two full-evidence model steps (heart surgery): (1) type then (2) connect. Same full Layer 0 evidence both times — not a skim, not filename. Separating them lets us verify “what is it?” before “what does it attach to?”

Inside the graph sort

Pass 1 — Type

Full Layer 0 JSON for one source. Returns one artifact_kind + citation. This is Path authority.

Pass 2 — Connect

Same evidence + unit typed inventory + Lesson spine. Returns edges only. Must not change kind.
