# Path A — Lesson plan workflow (proposed)

Auditor-only: **present / missing / misaligned from evidence**. Never invent lesson content.

## Academically proven ways to *review* a written lesson plan

These are the strongest research/practice bases for reviewing **written** plans (not classroom observation):

| Framework | What it checks | Why it matters for Loom |
|-----------|----------------|-------------------------|
| **Understanding by Design (UbD)** — Wiggins & McTighe | Backward design: goals → assessment evidence → learning activities must align | Catches “activities without a clear goal” and “tests that don’t match the objective” |
| **Madeline Hunter** mastery elements | Anticipatory set → objective → input → modeling → CFU → guided → independent → closure | Best research-backed **daily lesson structure** inventory (already our plate) |
| **Danielson Domain 1** (Planning) esp. 1c / 1e / 1f | Clear outcomes; coherent activities; assessments congruent with outcomes + planned formatives | Gold-standard planning rubric; we use it as a *document* checklist, not teacher eval |
| **Formative assessment research** — Black & Wiliam | Formatives must be planned, aligned to the learning intention, usable to adjust teaching | Separates real CFU/exit tickets from decorative quizzes |
| **T-TESS Dimension 1.1** (Standards & Alignment) | Measurable objectives aligned to **TEKS** (and related standards) | Texas-required planning language for our CTE context |
| **ELPS** (Texas) | Language objective / linguistic supports alongside content TEKS | Required for EB students; NW Unit Plan already expects this |
| **Curriculum audit triangulation** — Fenwick English | Written curriculum vs assessed evidence (and later taught) | Matches Crystallize/Loom auditor doctrine: match/mismatch, don’t grade the teacher |
| **Gradual Release** — Fisher & Frey | I do → we do → you do | Overlaps Hunter modeling / guided / independent; useful cross-check |

**We are not using** classroom-observation-only rubrics as primary Path A logic (full T-TESS Domains 2–3, walkthrough scores). Those need live teaching. Path A stays **written-curriculum audit**.

## Path A steps (A1 → A8)

Entry: router has already typed the document as `lesson_plan`.

| Step | Name | Academic anchor | What Loom does | Output |
|------|------|-----------------|----------------|--------|
| **A1** | Inventory cited chunks | Curriculum audit (documents as evidence) | Collect Layer 0 excerpts for this doc; list what exists | Chunk inventory |
| **A2** | Standards & learning intention | T-TESS 1.1 · UbD Stage 1 · Danielson 1c | TEKS / objective present? Observable student outcome? | PRESENT/MISSING + cites |
| **A3** | Backward design coherence | UbD Stages 1–2–3 alignment | Do assessment(s) and activities point at the same objective? Flag mismatches | Coherence findings |
| **A4** | Assessment path | Danielson 1f · Black & Wiliam | Formative (CFU/exit) vs summative path; formative leads toward objective | Assessment map |
| **A5** | Hunter structure matrix | Madeline Hunter · Gradual Release | Score 8 Hunter elements PRESENT/MISSING (structure only) | Structure matrix |
| **A6** | Model place evidence | (Loom method; auditor rules) | Model assigns **existing** excerpts → Hunter fields; blank if none fit | Filled `LESSON-PLAN` fields |
| **A7** | Access & language supports | ELPS · UDL (light) · NW CTAT accommodations | ELPS / SpEd / 504 / GT notes present or missing | Supports checklist |
| **A8** | Emit Path A artifacts | — | Write findings into unit packet path; `LESSON-PLAN.md/.pdf` | Artifacts for unit assemble |

### Guardrails (every step)

- Blank / MISSING = not found in materials  
- No authored activities, TEKS, or assessments  
- Model may **route and label** evidence; may not **create** content
