6. Router — figure out what it is, then split

route.py reads classification → picks a workflow. Same document never gets a one-size-fits-all analysis after this point. Unknown types → general path + feedback log.

Path A · Lesson plan

Lesson plan workflow

  1. Layer 1 place on calendar (shared idea, lesson-aware roles)
  2. Hunter / CTAT checklist Layer 2
  3. Model assigns excerpts → Hunter fields (fix for fill drift)
  4. Emit LESSON-PLAN.md/.pdf structure plate
Out: lesson completeness + filled Hunter sheet
Path B · Quiz / assessment

Quiz workflow

  1. Check answer key present?
  2. Item coverage vs unit TEKS / learning targets
  3. Formative vs summative role on the day grid
  4. No Hunter plate — assessment-shaped findings
Out: quiz audit rows for teacher packet
Path C · Everything else

General pass

  1. Slides, worksheets, rubrics, flyers, unknown…
  2. Current generic Layer 1–2 style analysis
  3. Log unknown types → _loom_feedback.yaml
  4. Later: promote hot patterns to their own workflow
Out: generic findings + feedback for growth
