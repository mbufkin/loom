# Lesson 5: Loops Review

**Course:** Computer Science I
**Duration:** 50 minutes
**Quality Tier:** Low

---

## TEKS Alignment

- §126.33(c)(2)(B)

## Learning Objective

Review loops.

## Rationale

Students need to review what they learned.

## Prerequisite Knowledge

Lessons 1-4

## Key Vocabulary

- Loop
- For
- While

---

### 1. Hook (5 min)

"Today we're reviewing loops. Everyone open your computers."

### 2. Objective (2 min)

"Today we will review for loops and while loops."

### 3. Instruction (15 min)

Just go over these examples again:

```python
for i in range(5):
    print(i)

x = 0
while x < 5:
    print(x)
    x = x + 1
```

### 4. Practice (20 min)

"Complete the worksheet. Questions 1-20. Work silently."

Worksheet contains 20 basic loop-tracing problems with no variety or application context.

### 5. Exit Ticket (3 min)

```
Name the two types of loops in Python:
1.
2.
```
