## Unit Summary

Students learn to write programs that repeat instructions using loops. Beginning with `for` loops (definite iteration), progressing to `while` loops (condition-controlled), then combining loops through nesting, and finally applying loops to real-world data processing. The unit culminates in a review and synthesis activity.

## Lesson Sequencing

| Lesson | Title | Quality Tier | Focus |
|--------|-------|-------------|-------|
| 1 | Introduction to Loops: The `for` Loop | Very High | Definite iteration, range(), sequence traversal |
| 2 | Condition-Controlled Loops: `while` | Very High | Indefinite iteration, sentinel patterns, infinite loop debugging |
| 3 | Nested Loops and Loop Patterns | Very High | Loop composition, 2D traversal, efficiency analysis |
| 4 | Loops in Data Processing | Medium | Practical data processing with loops |
| 5 | Loops Review and Synthesis | Low | Review activity, low cognitive demand |

## Summative Assessment

Unit coding project: Students write a program that processes a dataset using at least two types of loops, includes a nested loop, and handles user input with validation.
